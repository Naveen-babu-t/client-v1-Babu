Dan Vokey Plumbing — Phase 1 Static Website

This project is a Phase 1 static website prototype for a local plumbing business, Dan Vokey Plumbing, located in Kingston, Ontario.
The focus of this phase is layout, structure, accessibility, and clear user experience, not backend functionality.

📌 Project Purpose

Create a clean, professional business website

Practice semantic HTML, modern CSS, and basic JavaScript

Demonstrate accessibility and responsive design principles

Prepare a foundation for future dynamic features (Phase 2)

🧱 Pages Included

Home (index.html)

Business overview and value proposition

Call-to-action buttons (Call / Request Quote)

Popular services preview

Trust-focused messaging

Services (services.html)

List of common plumbing services

Clear explanations of what customers can expect

Static service descriptions (no booking logic)

About (about.html)

Business approach and values

Service area information

Focus on professionalism and communication

Contact (contact.html)

Static quote request form (client-side only)

Direct contact details

Business hours section

Confirmation message handled locally via JavaScript

🛠️ Technologies Used

HTML5
Semantic structure, accessibility landmarks, meta tags

CSS3
Custom layout, grid system, responsive design, dark/light theme support

JavaScript (Vanilla)

Mobile navigation toggle

Theme toggle (light/dark)

Static form confirmation behavior

Dynamic footer year
